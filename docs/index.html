What is CAB?

CAB (CodeAssistBench) is a comprehensive benchmark for evaluating AI coding assistants on real-world programming problems. It provides a standardized way to measure how well AI models can help with actual development challenges.

Key Features

Real-World Dataset

Curated from top-starred repositories with verified solutions and multi-turn conversations between users and maintainers.

Modular Architecture

Test any AI agent by implementing the CABAgent interface. Support for OpenAI, Claude, local models, and custom agents.

Automated Judging

Comprehensive evaluation including technical correctness, user satisfaction, Docker validation, and verbosity assessment.

Getting Started

1. Clone the Repository

git clone https://github.com/codingsoo/CAB.git
cd CAB

2. Install Dependencies

pip install -r requirements.txt

3. Try the Demo

# See what CAB can do
python scripts/try_cab.py

# Quick test with mock agent
python tests/integration/test_agent.py --agent mock --dataset data/converted_dataset.jsonl --max-issues 1

4. Run Your Own Tests

# Test with OpenAI GPT-4
python tests/integration/test_agent.py --agent openai-gpt4 --dataset data/converted_dataset.jsonl --max-issues 5
